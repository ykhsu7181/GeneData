# GeneData ADR-004 G4 调用面处置清单

## 1. 用途和限制

本清单是 `GeneData_ADR004_G4代码适用性与调用面审计_20261126.md` 的逐文件附录。它把大小写不敏感搜索 `dataset` 或 `FileRelation` 得到的候选文件分为：

- **删除/归档**：只服务旧迁移、旧 Dataset/FileRelation 写入或旧接口，待实施 Gate 批准后删除活动代码；历史 migration 和审计证据不删除；
- **重构保留能力**：保留业务能力，但实现必须改为 DataAsset、AssetFileMembership 和 ADR-005 批准的关系；
- **等待 ADR-005**：不能在最终关系、权限或专业实体边界批准前决定；
- **移除旧契约后重写**：G5 前清除旧表运行依赖，G7 再按新契约建设。

本清单是处置边界，不是删除授权。文件是否最终删除还须通过对应实施 diff、测试和新空库验证确认。

## 6. 使用方式

每个实施提交必须从本清单选择明确文件，不得全量暂存。完成某一批次时记录：

1. 实际修改或删除路径；
2. 替代事实来源和唯一 service；
3. 新旧测试变化；
4. 是否仍存在 Dataset/FileRelation 运行时引用；
5. migration、API、前端和生产状态；
6. 未处理文件及其后续 Gate。

实施过程中若发现本清单未覆盖的新调用，先更新审计证据和处置结论，再继续删除。
