## 5. 生产服务器下一门禁

在生产服务器执行前应先备份数据库，并确认 `manual_files` 快照。然后只做实体验证：

```bash
python manage.py validate_manual_files \
  --path /home/labuser/rdcheng/gd/manual_files \
  --output-dir audit_reports/external_file_registration_20261022 \
  --checksum sha256 \
  --fail-on-errors
```

随后使用候选 Manifest 执行 dry-run：

```bash
python manage.py import_hierarchy_file_manifest \
  --file metadata/external_file_registration_20261022/files.registration.candidate.tsv \
  --manual-files-dir /home/labuser/rdcheng/gd/manual_files \
  --output-dir audit_reports/external_file_registration_20261022 \
  --dry-run
```

只有物理文件数量、大小、格式、SHA-256、层级关系和 dry-run 报告全部通过后，才能制定分批 `--apply` 清单。30 条复核项在关系确认前不得导入。
